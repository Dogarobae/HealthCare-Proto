# HealthCare

Aplicación web para registrar pacientes y recomendar medicamentos.

## Tecnologías
- Java Spring Boot
- React
- H2 Database
- Spring Security
- OpenFDA API

## Estructura

receta-api -> backend Spring Boot  
receta-frontend -> frontend React

## Ejecutar backend

cd receta-api
./gradlew bootRun

## Ejecutar frontend

cd receta-frontend
npm install
npm run dev
